# Contributing to KodeArrow

Thank you for your interest in contributing to KodeArrow! We welcome contributions from the community to help make this tool even better.

## How to Contribute

### 1. Reporting Bugs
- Use the [Issue Tracker](https://github.com/bted/KodeArrow/issues).
- Describe the bug clearly and provide steps to reproduce it.
- Include your OS and Python version.

### 2. Suggesting Enhancements
- Open a "Feature Request" in the Issue Tracker.
- Explain why the feature would be useful.

### 3. Submitting Pull Requests
- Fork the repository.
- Create a new branch (`feature/your-feature-name` or `bugfix/your-bug-name`).
- Ensure your code follows the project's architecture and coding standards.
- Run tests (if applicable) before submitting.
- Link your PR to the relevant issue.

## Coding Standards
- Follow PEP 8 for Python code.
- Use meaningful variable and function names.
- Document new modules and complex logic.
- Ensure 0 coupling between core services and UI.

## Environment Setup
1. Clone the repo.
2. Install dependencies: `pip install -r requirements.txt`.
3. Copy `.env.example` to `.env` and configure your keys.
